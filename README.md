# Bazar-e-Pak Server

Backend API for the Bazar-e-Pak e-commerce platformmmm.

## Tech Stack

- Bun
- Express.js
- MongoDB
- Mongoose
- Zod
- JOSE
- Helmet
- CORS
- Express Rate Limit

## Architecture

The server follows a scalable modular architecture with separate layers for:

- Routes
- Controllers
- Services
- Validation
- Models
- Middleware
- Configuration

## Features

- Product management
- Shop management
- Authentication & authorization integration
- Role-based access control
- Request validation
- Centralized error handling
- Rate limiting
- Secure API configuration
- MongoDB database integration
